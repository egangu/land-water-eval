# Data

`land_water_gt_2deg.csv` contains labels derived from the intermediate-resolution
GSHHS component of GSHHG, maintained by Paul Wessel and Walter H. F. Smith.
Source: [NOAA/NCEI](https://www.ngdc.noaa.gov/mgg/shorelines/shorelines.html).
